# @intl-t/next

`@intl-t/next` brings [intl-t](https://www.npmjs.org/package/intl-t) to Next.js, with helpers for navigation, middleware, RSC/server components, and locale-aware links that integrate with App Router and caching while keeping full types on your translation tree.

[**→ Check out the Intl-T Website**](https://intl-t.dev)
