# @intl-t/locales

`@intl-t/locales` provides locale typing and helpers shared across [intl-t](https://www.npmjs.org/package/intl-t) packages, ensuring consistent ISO codes and metadata when negotiating and formatting languages.

[**→ Check out the Intl-T Website**](https://intl-t.dev)
