# @intl-t/declarations

`@intl-t/declarations` is a tiny CLI/library to generate TypeScript declaration files from your [intl-t](https://www.npmjs.org/package/intl-t) translation JavaScript objects, keeping autocompletion and strict types aligned with your source.

[**→ Check out the Intl-T Website**](https://intl-t.dev)
