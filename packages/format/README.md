# @intl-t/format

`@intl-t/format` offers formatting and injection utilities for [intl-t](https://www.npmjs.org/package/intl-t): ICU message parsing, variable interpolation, and helpers to build rich outputs (strings or elements) with consistent, type-friendly behavior.

[**→ Check out the Intl-T Website**](https://intl-t.dev)
